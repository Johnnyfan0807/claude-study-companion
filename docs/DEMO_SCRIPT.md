# Two-minute demo script

## 0:00–0:20 — Problem

“Students often have lecture notes but do not know how to turn them into active learning. I
built Claude Study Companion to bridge that gap. It uses a student's own material and focuses
on understanding rather than writing assessed answers for them.”

## 0:20–0:45 — Input and control

Upload a short Probability and Statistics note or click **Use demo notes**.

“The app accepts pasted notes and common lecture-file formats. Before every generation it uses
Claude's token counter, enforces the limit selected here, and shows actual usage and estimated
cost. The API key is kept outside the repository.”

## 0:45–1:15 — Fast learning tools

Generate a balanced summary, then switch to the practice set and open the answer-key expander.

“Students can create a structured review and then immediately practise retrieval. Answers stay
hidden until the student chooses to reveal them.”

## 1:15–1:50 — Differentiator

Open Socratic Mode with: `Why is the positive predictive value only about 16% in this example?`

Reply imperfectly to Claude's first question, then press **I’m stuck — one more hint**.

“The key feature is Socratic Mode. Claude asks one focused question at a time, diagnoses the
student's reasoning, and gives a smaller hint instead of immediately solving the problem.”

## 1:50–2:00 — Close

“This connects my Probability and Statistics teaching experience with practical Claude API
development. The next step is a lecturer-reviewed evaluation and authenticated student quotas.”
